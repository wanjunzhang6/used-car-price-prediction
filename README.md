# 二手车交易价格预测 - 数据挖掘实战项目
## 项目简介
天池零基础入门数据挖掘学习赛项目，使用Python完成二手车价格回归预测，完整走完数据分析全流程，适合数据运营/数据分析简历项目。
**任务目标**：根据车辆各项特征，预测二手车的成交价格。

## 技术栈
Python、Pandas、Matplotlib、Seaborn、LightGBM、Jupyter Notebook

## 项目流程
1. 数据读取：加载训练集train.csv、测试集test.csv
2. 数据清洗：处理缺失值、异常值，去除无效样本
3. EDA探索性分析：统计分布、相关性可视化，分析各特征与价格的关系
4. 特征工程：筛选有效特征，处理类别特征
5. 模型建模：LightGBM回归模型训练，评估模型MAE指标
6. 结果输出：对测试集预测，生成预测结果文件

## 文件说明
- used_car.ipynb：完整代码文件（Jupyter notebook）
- report.md：项目分析报告
- result.csv：测试集预测输出文件

## 项目总结
本项目完整复现数据分析挖掘工作流，熟悉数据清洗、可视化、建模的基础思路。
模型使用LightGBM，平均绝对误差MAE作为评价指标；
可优化方向：特征组合、对数变换、调参、尝试多个模型对比
